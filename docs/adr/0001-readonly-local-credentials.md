# ADR 0001：只读复用本机已有登录态，不自建登录体系

- **状态**：已采纳（2026-11-23）

## 背景
`mac_tool` 需要监控 Codex、Cursor、Antigravity 三个工具的额度，存在三种关联方案：
1. 内嵌 WebView 让用户重新登录并保存 Cookie/Token
2. 手动粘贴 Token/Cookie 存入 Keychain
3. 只读复用本机三个工具已有的本地登录凭据

## 决策
采用方案 3：**只读复用本机已有登录态**，不自建账号系统，不内嵌 WebView，不保存任何密码。凭据只在内存中使用，严禁写入磁盘、日志或共享缓存，严禁修改或刷新原工具的凭据文件/数据库。

## 后果
- **正面**：零重复登录体验、最小化凭据暴露面、架构极简、开源审计透明度高。
- **负面 / 约束**：依赖各工具本地凭据格式；主应用不能开启 macOS App Sandbox（因此不上架 Mac App Store），且当原工具登录过期时需引导用户回原工具重新登录。
