# Triage 标签映射

各工程技能按五个标准分诊角色描述状态；本文件将这些角色映射到本仓库 Issue Tracker 实际使用的标签名。

| 技能中的标准角色 | 本仓库实际标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者待评估该 Issue |
| `needs-info` | `needs-info` | 等待提交者补充更多信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已明确，可交由 agent 自动执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不计划处理 |

当技能提及某个分诊角色（例如“打上 `ready-for-agent` 标签”）时，统一使用上表“本仓库实际标签”列对应的字符串。

如需改用自定义标签，直接修改“本仓库实际标签”列即可。
